# Java Learning Summary

## Core Fundamentals
- **Java Basics**: Class structure, `main()` method, identifiers, naming conventions, primitive types (8), reference types
- **Literals & Constants**: Integer (decimal/octal/hex/binary), floating-point (`3.14f`), `final` constants
- **Operators**: Arithmetic, assignment (`+=`), comparison, logical, bitwise, ternary (`?:`)
- **Control Flow**: `if/else/switch`, loops (`for/while/do-while`), `break/continue`

## Object-Oriented Programming
- **OOP Pillars**: Encapsulation (`private` fields + getters/setters), Inheritance (`extends`), Polymorphism, Abstraction
- **Classes & Objects**: Constructors, `this`, method overloading/overriding (`@Override`), `static` members
- **Advanced OOP**: Abstract classes/methods, Interfaces (`implements`), `super`, `final` (class/method/field)

## Collections & Generics
- **Collections Framework**: `ArrayList`, `LinkedList`, `HashMap`, `Vector` (thread-safe)
- **Generics**: Type-safe collections (`List<Integer>`), generic classes/methods (`<T>`)
- **Iterators**: `Iterator`, enhanced for-each loops, `Collections` utility (sort, reverse, min/max)

## File I/O & Streams
- **Streams**: Byte streams (`InputStream/OutputStream`), Character streams (`Reader/Writer`)
- **File Operations**: `File` class, `FileInputStream/OutputStream`, `BufferedReader/Writer`
- **Core Utilities**: `String/StringBuffer`, `Math` (random, PI), `Calendar`, Wrapper classes (auto-boxing)

# Java 학습 요약

## 핵심 기초
- **자바 기본**: 클래스 구조, `main()` 메서드, 식별자, 네이밍 규칙, 기본형(8가지), 참조형
- **리터럴 & 상수**: 정수(10/8/16/2진수), 실수(`3.14f`), `final` 상수
- **연산자**: 산술, 대입(`+=`), 비교, 논리, 비트, 삼항(`?:`)
- **흐름 제어**: `if/else/switch`, 반복문(`for/while/do-while`), `break/continue`

## 객체지향 프로그래밍
- **OOP 4대 요소**: 캡슐화(`private` + getter/setter), 상속(`extends`), 다형성, 추상화
- **클래스 & 객체**: 생성자, `this`, 메서드 오버로딩/오버라이딩(`@Override`), `static` 멤버
- **고급 OOP**: 추상 클래스/메서드, 인터페이스(`implements`), `super`, `final`

## 컬렉션 & 제네릭
- **컬렉션 프레임워크**: `ArrayList`, `LinkedList`, `HashMap`, `Vector`(스레드 안전)
- **제네릭**: 타입 안전 컬렉션(`List<Integer>`), 제네릭 클래스/메서드(`<T>`)
- **이터레이터**: `Iterator`, 향상된 for-each, `Collections` 유틸리티(정렬, min/max)

## 파일 입출력 & 스트림
- **스트림**: 바이트 스트림(`InputStream/OutputStream`), 문자 스트림(`Reader/Writer`)
- **파일 처리**: `File` 클래스, `FileInputStream/OutputStream`, `BufferedReader/Writer`
- **핵심 유틸리티**: `String/StringBuffer`, `Math`(random, PI), `Calendar`, 래퍼 클래스(오토박싱)
